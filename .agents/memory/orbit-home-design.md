---
name: Orbit Home design direction
description: Product scope and visual requirements that should guide future design iterations.
---

Orbit Home is a call-center workspace for agents handling up to two concurrent chats. The user requested only the exterior design, not live-chat infrastructure.

**Why:** The user explicitly limited this phase to a visual prototype.

**How to apply:** Keep design iterations in the mockup unless the user asks to implement the functional product.

Conversation tabs must resemble Google Chrome tabs, including the active tab joining the chat panel and the transition when switching customers. Separate rounded cards or rectangles merely touching each other did not satisfy the user, who corrected this repeatedly.

**Why:** The user wants an integrated browser-tab appearance, not floating conversation buttons. They confirmed “está mejor” for the curved lower shoulders and active tab merging into the chat header; preserve that direction.

**How to apply:** Judge the rendered silhouette and its connection to the chat surface, not just whether the CSS gap is zero. Preserve the idle-color indicators and the new-chat green pulse.

The latest reference request supersedes the earlier 60/40 split: left navigation, a wide chat area, and a narrower customer panel. The user returned to a darker design after exploring a light Lark reference.

The user explicitly dropped the glass treatment: “ya no lo hagamos glass”, requesting the reference colors and aqua messages.

**Why:** This supersedes the earlier translucent lilac/gray visual direction.

**How to apply:** Keep surfaces solid and opaque; do not reintroduce glass blur or translucent bubbles based on older requests.

**Why:** These are explicit layout and appearance requirements.

**How to apply:** Preserve integrated conversation tabs and follow the latest reference proportions, not the old 60/40 split. The requested navigation is Dashboard (monthly NPS, chats handled, first call resolution, closed ticket rate), Contactos (Supervisor, Manager, QA, HR), Conversations, and KB at the bottom. Header says Chat Support with Orbit Home beneath it and a notification bell, without a search bar.
